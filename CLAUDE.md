# Network Index Toolkit

Scripts that turn a LinkedIn export (plus optional calendar and notes exports) into a searchable markdown index of a professional network. See README.md for the pipeline.

## Rules
- **This repo is PUBLIC.** Never commit real contact data: no LinkedIn exports, calendar files, notes, generated per-person files, `config.py` or anything with names, emails or messages. Use only fictional examples (e.g. "Jane Smith").
- Keep personal run scripts and real data outside this repo.
- This is the only repo to update for Network Index work. The old private `network-index` repo is archived and must not be changed.
- Licence is all rights reserved (see LICENSE). Don't change the licence or add one without the owner's explicit say-so.
- Before every commit, check `git status` and `git diff` for anything personal.
